# Legal texts for **Daily Quote**

This folder is intended to be used as a basis for a **separate public GitHub repository** that will host the legal documents for the *Daily Quote* app (Android).

Recommended structure:

- `PRIVACY_POLICY.md` – full Privacy Policy (EN / UK / RU) that you will link from Google Play Console.
- `TERMS_OF_USE.md` – app Terms of Use (EN / UK / RU).
- `LICENSE` – license for the text in this repository (currently MIT).

After you push this folder to a standalone repo, you can:

1. Enable **GitHub Pages** (or any static hosting).
2. Use the public URL to `PRIVACY_POLICY.md` (or its rendered HTML) as the **Privacy Policy URL** in Google Play Console.
